本 Release 提供包含全部原始测试负载的 v2 完整课程复现包，解压即可离线准备数据并一键复现，无需另行下载 SIFTsmall、SIFT1M 或 GloVe25。

## 附件清单

- `cpu-exact-vector-search-v2.0-course-full.zip`：完整 v1/v2 自研源码、三份标准测试负载、双机 78 项实验证据、Z3 形式化验证材料与一键复现入口。
- `51295903131_赵信喆_系统优化课程报告_v2.pdf`：14 页完整课程研究报告（融合 v1 跨层基础与 v2 整数内积升级，含 6 张 300 DPI 中文分析图表）。
- `SHA256SUMS.txt`：上述附件的 SHA256 校验值。

> 提示：GitHub 自动生成的 `Source code` 压缩包不含大体积原始数据集，请下载完整复现包 ZIP 进行完整复现（或配合 `python3 tools/import_release_data.py <完整ZIP>` 将已校验负载导入源码目录）。

## 一键复现步骤

在 Linux x86-64 或 WSL2 终端解压完整包并进入根目录执行：

```bash
python3 verify_bundle.py
bash reproduce.sh --check-env
bash reproduce.sh --quick   # 快速验收：编译、回归、三组 Z3 形式化验证、SIFTsmall 与 PDF 生成
bash reproduce.sh           # 完整复现：本机 26 配置校准/复用 + 78 项 Faiss 同轮对照
```

- 三份原始数据集已随包提供；仅首次安装缺失系统或 Python 依赖时可能需要联网及相应权限。
- 首次 26 配置校准（含答案缓存）：本机约 769.9 秒，服务器约 1,668.5 秒；指纹命中复用仅需 7.4 秒（本机）/ 13.7 秒（服务器）；完整模式另含全量 78 项对照，建议预留数小时。

## v2 归档主要结果

- **本地 Core Ultra 9 275HX（v2 自动校准版）**：**78/78 领先**最快适用 Faiss 路径，正确性 78/78，几何平均加速比 **2.488×**（SIFT1M 2.738×，峰值 **7.356×**；GloVe25 1.919×）；SIFTsmall 早期分层消融相对全排序提速 **9.43×**。
- **学校 Xeon Gold 6133（v2 自动校准版）**：**78/78 领先**最快适用 Faiss 路径（由 v1 自动校准 67/78 提升至全面领先），正确性 78/78，几何平均加速比 **1.512×**（最小 **1.085×**，最大 **2.384×**）；大批量配置通过消除 512 条 `vpsubw` 与自适应选用 `block=128` 全部转为领先。
- **形式化验证**：Z3 4.8.12 完成 36 项有界 Top-K 抽象模型 + 4 项无损字节算术 + 5 项 v2 整数范数内积引理验证与双变异反例证伪。

以上性能数据对应报告记录的机器与单线程配置（固定 `OPENBLAS_CORETYPE=Haswell`），在新机器上运行将自动生成本机实测报告。基准数据集与第三方依赖的来源及学术引用见 `DATA_SOURCES.md`。
