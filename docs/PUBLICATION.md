# 公开发布说明（v2.0-course）

本仓库及 `v2.0-course` Release 面向《软件系统优化》课程评测与可复现性验证整理发布：

- **源码与报告仓库**：包含完整的 v1 与 v2 自研 C++/Python 源码、14 页融合研究报告（MD/PDF）、6 张 300 DPI 中文配图与可追溯绘图/渲染脚本、核心实验证据以及 Z3 形式化验证材料；大体积原始数据集不直接纳入 Git 历史跟踪。
- **完整课程复现包（Release 附件）**：`51295903131_赵信喆_系统优化完整提交包_v2.zip`（发布时对应 `cpu-exact-vector-search-v2.0-course-full.zip`）随包附带全部三份标准原始负载与完整归档证据，支持解压后完全离线准备数据并一键复现。
- **完整性与环境记录**：源码与完整包均通过根目录 `MANIFEST.json` 与 `verify_bundle.py` 逐文件校验 SHA256；姓名与学号按课程署名规范保留，历史实验记录中的硬件与路径信息仅作为实测溯源证据，不含任何凭据或私钥。
- **数据来源与引用**：各基准数据集来源、哈希与许可说明统一记录于 `DATA_SOURCES.md` 与 `DATA_MANIFEST.json`。
