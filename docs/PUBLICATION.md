# 公开发布说明

目标为公开GitHub仓库及公开Release，老师下载完整ZIP后直接复现。仓库不跟踪大体积负载；Release完整ZIP包含全部原始负载、源代码、历史结果和报告。

公开附件移除了两份仅用于学校机器的历史调度脚本 `autotune/launch_server.py`、`autotune/server_runner.py`，不改搜索、校准、数据准备及验证入口。姓名、学号按课程署名保留；历史证据中的本机路径和CPU信息是实验记录，不是连接凭据。未篡改历史测量数据或硬件指纹。

扫描覆盖完整ZIP的文本、嵌套ZIP及PDF文本，未发现所检查的私钥、常见访问令牌或明文密码格式。扫描不是对所有潜在凭据形式的数学保证。没有把本地审阅草稿和个人配置加入公开源码目录。

新增DATA_SOURCES、DATA_MANIFEST、DATA_RIGHTS_STATUS用于记录数据来源、完整性和再分发核查状态。SIFT上游授权尚未确认，不能把这次技术验收描述为数据许可全部通过。所有数据均按用户要求保留；本次只在本地准备文件，没有推送或发布线上Release。

公开ZIP使用新的根目录MANIFEST。各子目录旧file_hashes、旧验收记录是原历史记录，移除旧调度脚本后不得拿它们代替本次发布清单。
