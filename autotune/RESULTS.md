# 自动校准验收结果

学校服务器 Xeon Gold 6133，逻辑 CPU 19，nice=15、I/O idle，原版本保持不变。

- 完整校准：26/26 个配置，两个独立调优批次、两个独立验证批次，各重复五次。
- 独立正确性：52/52 个配置—验证批次通过，自研字节路径 ID/距离精确验证，浮点路径按原协议容差验证。
- 自动改选内核：5/26 个配置；其他配置保留原分流。改变项的独立验证范围见下表。
- 第一次完整校准耗时：1943.2 秒（包括编译、构建、独立答案计算、测量和验证）。
- 第二次执行：复用 26/26，重新校准 0 项，耗时 11.2 秒（仍有编译和数据库身份检查成本）。
- 原分流同轮对照使用同一自研库的原始 mode 7；不是重新测量 Faiss，也不是之前 78 项比较的新结论。

运行方法见 README.md。当前源码、调优原始计时、选择配置、独立验证与两次执行日志均保留。profiles/host.json 只适用于匹配的机器、代码和数据库；另一台机器应运行校准命令生成自己的配置。

该包不重复包含大数据集及本地编译库。需要原项目准备的数据、NumPy、g++ 与 binutils；运行时重新编译。未支持的 Q/K 或数据类型安全回到原分流。

复用路径最初在汇总缓存条目时出现重复 label 字段异常，随后仅修复汇总代码并重新执行验证。旧日志、修复前驱动源码、修复前配置和策略指纹迁移审计保留；所有内核、选择条目、原始计时和正确性记录未改变。详见 cache_reporting_fix_audit.json。


本地二次验收：将服务器配置带到 Core Ultra 9 275HX / WSL 后，身份不匹配被正确识别，使用原分流回退。候选与缓存回归再次通过。原正式提交包 SHA256 未变化。详见 local_validation/。
